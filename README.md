# 💰 BudgetFlow - Advanced Personal Finance Tracker

BudgetFlow is a premium, high-performance personal finance dashboard built with Next.js, Tailwind CSS, and Framer Motion. It allows users to track income/expenses, set monthly budget goals, and visualize financial trends with beautiful charts.

## ✨ Features

-   **🌓 Dark Mode Support** - Seamlessly switch between light and dark themes with system preference detection.
-   **📊 Dynamic Visualizations** - Interactive charts (Monthly Trends & Category Breakdowns) powered by Recharts.
-   **🎯 Category Budgets** - Set monthly spending limits per category and track progress with real-time visual feedback.
-   **🔍 Advanced Filtering** - Powerful search and filtering by type, category, and date range.
-   **📥 CSV Export** - Export your filtered transactions to CSV for further analysis.
-   **🔄 Recurring Transactions** - Mark transactions as monthly recurring for better fixed-cost tracking.
-   **📱 Responsive Design** - Fully optimized for mobile, tablet, and desktop with a custom mobile card view.
-   **✨ Smooth Animations** - Polished micro-interactions and layout transitions using Framer Motion.
-   **🛡️ Robust Data Management** - Persistent client-side storage with Zustand (persisted across sessions).

## 🛠️ Tech Stack

-   **Framework:** Next.js 14+ (App Router)
-   **Styling:** Tailwind CSS
-   **Components:** shadcn/ui
-   **State Management:** Zustand
-   **Animations:** Framer Motion
-   **Charts:** Recharts
-   **Icons:** Lucide React
-   **Forms:** React Hook Form + Zod
-   **Notifications:** Sonner

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/nethmith/Budget-Dashboard.git
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
